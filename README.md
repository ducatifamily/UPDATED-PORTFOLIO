# Kristina Noriega Professional Portfolio

This is the complete Render-ready portfolio package.

## IMPORTANT: upload all files to the ROOT of the GitHub repository

Do not upload the ZIP itself.

After unzipping, the repository should look like this:

- index.html
- styles.css
- app.js
- render.yaml
- README.md
- headshot.jpg
- ed780-retention.png
- gemini-ecosystem.png
- community-engagement.png
- avicenna-cohort.png
- github-render-ecosystem.png
- render-services.png

There is intentionally NO assets folder in this version. Keeping every file at the repository root prevents the image-folder upload problem that caused broken visuals on Render.

## Render

Repository: `ducatifamily/Kristina-Noriega-Portfolio`

If Render is already connected to the repository, committing these files should trigger a redeploy automatically.

After Render shows **Live**, hard-refresh the site with:
- Windows: Ctrl + Shift + R
- Mac: Command + Shift + R
